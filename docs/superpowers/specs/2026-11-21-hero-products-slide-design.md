# Дизайн: третий слайд hero-слайдера «Популярные модели»

**Дата:** 2026-11-21 · **Статус:** реализовано (итерация 2)

## Задача и почему

Красивый баннер на главной с реальными фото трёх товаров. Сейчас в hero два
текстовых слайда (01 бренд, 02 решения) и одна SVG-иллюстрация-заглушка —
настоящих фотографий на первом экране нет вообще.

## Подход

Итерация 1 (белые фото-карточки в ряд) — отклонена пользователем: «просто
карточки», не соответствует стилю. Итерация 2 — **плавающие товары с
выносками** (выбрана из трёх вариантов: сцена-подиум, витрина-полка,
плавающие товары). Товарные фото вырезаются из белых фонов в прозрачные PNG
и компонуются на тёмном hero в стиле SQUADRO.

## Что сделано

- Слайд 03 «Хиты продаж» в `HeroSlider.tsx`:
  - **desktop (lg+)**: композиция на правой колонке — оранжевое свечение,
    тонкие рамки-квадраты, три парящих выреза (СЛИМ 500 центральный крупный,
    МАСТЕР 600 слева ниже, ЮНИОР СМАРТ 600 справа выше), выносные подписи
    «название + цена» с линией и квадратной точкой; лёгкая анимация парения
    (hero-float, stagger, respects prefers-reduced-motion);
  - **mobile**: упрощённый ряд из трёх вырезов с подписями под ними;
  - товары кликабельны (ссылки на карточки), выноски — текстовые дубли
    (aria-hidden), нумерация слайдов справа не перекрывается (pr-10).
- Обработка изображений (разовый скрипт PIL+numpy, удалён после запуска):
  flood-fill белого фона от краёв (порог по max-каналу 190), для ЮНИОРа —
  дополнительно крупнейшая тёмная компонента + 2px кайма (убирает серые
  клоки фоновой тени), эрозия 1px против белой каймы, Gaussian-растушёвка
  альфы, обрезка по bbox, LANCZOS-даунскейл до ~2x экранного размера.
  Итог — `public/images/hero/{slim-500,master-600,yunior-600}.png`.
- Данные: `page.tsx` запрашивает товары по `HERO_PRODUCT_SLUGS`
  (slim-500, master-600, yunior-600-0-6-kva), фиксированный порядок,
  товар без фото пропускается; пустой список → слайд не рендерится.
  Маппинг slug→локальный вырез — `HERO_CUTOUTS` в HeroSlider, фолбэк на
  фото с площадки в mobile-варианте.

## Не делается / анти-цели

- Не трогаем слайды 01/02, SVG-заглушку `UpsImage`, структуру страницы ниже hero.
- Никаких акций/скидок в баннере — только витрина товаров.
- Без внешних зависимостей для вырезания фона (rembg и т.п. не нужны:
  товары тёмные на белом, пороговая заливка достаточно чистая).
