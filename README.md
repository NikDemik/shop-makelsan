# MAKELSAN Маркет — интернет-магазин ИБП

Современный магазин источников бесперебойного питания бренда **Makelsan**.
Каталог и контент синхронизируются с базой производителя по API `base.sstmk.ru`
(инструкция в `docs/api`), цены конвертируются из USD в рубли по курсу ЦБ РФ.

Проект выполнен по аналогии с Shop-impuls (Next.js 15 + Prisma + PostgreSQL):
структура витрины, кабинета и админки идентична, отличается только каталог —
ветка бренда **MAKELSAN** дерева категорий API (on-line ИБП 10–1000 кВА).

## Стек

- **Next.js 15** (App Router, Server Actions) + **TypeScript**
- **Tailwind CSS v4** (палитра: графит + «тёплый» оранжевый — фирменный цвет корпусов Makelsan)
- **PostgreSQL 16** (Docker) + **Prisma ORM**
- Аутентификация: JWT-сессии (jose) в httpOnly-cookie, пароли bcrypt
- Корзина: zustand с сохранением в localStorage

## Запуск

```bash
# 1. База данных (порт 5435, чтобы не конфликтовать с другими проектами)
docker compose up -d

# 2. Зависимости
npm install

# 3. Схема БД
npx prisma db push

# 4. Синхронизация каталога с API base.sstmk.ru (категории + товары Makelsan)
npm run sync

# 5. Администратор
npm run seed:admin

# 6. Сайт
npm run dev        # http://localhost:3000
```

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | admin@makelsan-ups.ru | admin123 |

Доступ к API задаётся в `.env`: `BASE_API_URL`, `BASE_API_LOGIN`, `BASE_API_PASS`
(креды площадки — в `docs/.env`).

## Как устроены данные

**Синхронизация (`scripts/sync-api.ts`)**

1. Дерево категорий API → ветка бренда «MAKELSAN» → дочерние категории = **серии**
   (Boxer, Boxer S, Boxer S RM, LevelUPS, LevelUPS T3, LevelUPS T4 и др.).
2. Товары запрашиваются по каждой серии (у API лимит 500 за запрос без offset),
   плюс товары, привязанные к корню ветки. Дедупликация по `id`.
3. На каждый товар: артикул, слаг, цены (`price`/`sale_price` в USD),
   изображения (`image` + `images` через `;`), файлы документации
   (`files_titles` в формате `cat#-#Название##путь`), HTML-блоки описания,
   таблица модификаций (парсится в JSON), характеристики (непустые поля с
   подписями из `get_fields`), флаги применения (`ibp_home`, `dlya_cod`, ...).
4. **Цены в рублях**: курс берётся с ЦБ РФ (`Setting: usd_rate`), `priceUsd × rate`.
   Если цены в API нет — товар отображается как «цена по запросу».
5. Исчезнувшие из API товары деактивируются (`active=false`), ручная цена админа
   (`priceOverrideKopecks`) синхронизацией не затрагивается.

Повторный запуск `npm run sync` обновляет каталог (безопасно, идемпотентно).

**Изображения и файлы** отдаются площадкой `base.sstmk.ru` — в БД хранятся
относительные пути, на витрине подставляется абсолютный URL (`baseAssetUrl`).

## Функциональность

**Витрина** — главная (hero-слайдер, решения по отраслям, серии, популярные
модели), каталог с фильтрами (серия, тип ИБП, мощность кВА, «только с ценой»,
сортировка, пагинация), страницы серий с клиентским подбором и таблицей моделей,
карточка товара: галерея, цена, характеристики из API, HTML-блоки (описание,
преимущества, внешний вид, установка, комплектация), модификации (складские
варианты подсвечены), документация PDF, похожие товары.

**Покупка** — корзина, оформление заказа с типом покупателя (B2C/B2B),
доставкой (самовывоз / ТК) и оплатой (карта / при получении / счёт).
Для B2B — скидка 5%, реквизиты. Товары без цены — кнопки «Запросить цену».
Остатков в API нет, поэтому сток не списывается.

**Личный кабинет** — обзор, история заказов со статусной шкалой, профиль.

**Админ-панель** (`/admin`) — дашборд (выручка, график 14 дней, топ товаров,
товары с ценой «по запросу»), управление заказами (статусы), товары
(поиск, вкл/выкл в каталоге, ручная цена в рублях), пользователи.

**Контент** — решения по отраслям (6 лендингов на флагах применения из API),
база знаний (3 статьи), документация (библиотека PDF из файлов товаров),
о бренде, доставка, гарантия, контакты, политика.

## Структура

```
prisma/schema.prisma   схема (User, Series, Product, Order, OrderItem, Setting)
scripts/sync-api.ts    синхронизация API base.sstmk.ru → PostgreSQL
scripts/seed-admin.ts  создание администратора
src/lib/base-api.ts    клиент API (POST form-urlencoded, login + md5(pass))
src/lib/               prisma, auth, cart, format, seo, solutions, kb
src/actions/           server actions (auth, admin)
src/app/               страницы (витрина, кабинет, админка, /api/orders)
src/components/        UI-компоненты
src/middleware.ts      защита /account, /admin, /checkout
```
